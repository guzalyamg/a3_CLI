# a3_CLI

MiniSearch Project
About

This is my small Python project where I made a simple search engine. The program takes some text documents (demo corpus) and lets the user search with words or small queries. I did this project to practice Python and understand how searching works.

Features

Works with demo text corpus.

User can choose tokenizer (basic if you press enter).

Two modes: plain and simple.

Supports queries with AND / OR / NOT.

Can set a limit for how many results to show.

How to Run

Open terminal in the project folder.

Run this command:

python -m minisearch.cli


Then answer the program questions (yes/no, tokenizer, mode, query).
